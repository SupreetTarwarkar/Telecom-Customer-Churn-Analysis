# Dataset

This project uses `telecom_churn_data.csv`, containing **7,043 customer records** and **21 columns**.

## Dataset Dimensions

- **Rows:** 7,043
- **Columns:** 21

## Data Categories

The dataset includes the following customer information:

- **Customer Identification**
  - Customer ID

- **Demographics**
  - Gender
  - Senior Citizen
  - Partner
  - Dependents

- **Account Information**
  - Tenure
  - Contract Type
  - Paperless Billing
  - Payment Method

- **Phone Services**
  - Phone Service
  - Multiple Lines

- **Internet & Add-on Services**
  - Internet Service
  - Online Security
  - Online Backup
  - Device Protection
  - Tech Support
  - Streaming TV
  - Streaming Movies

- **Billing Information**
  - Monthly Charges
  - Total Charges

- **Target Variable**
  - Churn

## Purpose

The dataset is used to analyze customer churn patterns across demographics, services, billing behavior, contract type, and account characteristics.
